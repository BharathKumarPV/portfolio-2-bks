# Portfolio 2 (BK's) — Bharath Kumar P.V

Interactive 3D particle hero portfolio featuring WebGL dots animation, reveal transitions, dynamic project showcase, tech stack universe, and smooth scroll effects.

## 🚀 Live Demo
- **Live Website**: [https://portfolio-2-bks.vercel.app](https://portfolio-2-bks.vercel.app)
- **GitHub Repository**: [https://github.com/BharathKumarPV/portfolio-2-bks](https://github.com/BharathKumarPV/portfolio-2-bks)

## 🛠️ Features & Stack
- **Three.js & Custom WebGL Shaders**: Interactive particle cloud hero (`dots.bin`) with camera choreography and responsive lighting.
- **Pure Static Architecture**: Fast load times, zero-latency rendering, responsive mobile & desktop layout.
- **Visual Effects**: Particle embers, tilt interactions, magnetic buttons, dynamic journey timeline, and ambient glow.
- **Sections**:
  - 3D Particle Cloud Hero with "Reveal" action
  - 01 · About
  - 02 · What I Build
  - 03 · Beyond the Code
  - 04 · Tech Universe
  - 05 · A Journey Through Code (Interactive Timeline)
  - 06 · Projects Showcase
  - Connect & Social Links

## 📦 Project Structure
- `index.html` — Main HTML page with embedded styles and interaction loops.
- `hero.js` — Three.js WebGL canvas rendering engine and particle controller.
- `dots.bin` — Binary point cloud data for 3D dot matrix representation.
- `photo-cutout.webp` — Optimized transparent portrait asset.
